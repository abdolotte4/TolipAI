## How This Works

1. You run `./launch-aider.sh` in the Shell tab and chat with Aider
2. When you `/quit` Aider, `scripts/post-aider.sh` runs automatically
3. It checks every file Aider changed: black formatting, flake8 lint, uncommitted changes
4. Results are written here
5. Next time you talk to Replit Agent, it reads this log and fixes anything Aider missed — without you having to ask
