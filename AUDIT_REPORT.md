## Executive Summary

This codebase was generated by Replit AI Agent and originally contained significant amounts of fantasy/hallucinated code — modules that looked functional but could not actually produce real data. A fix guide was issued prescribing removal of LLM-based extraction, AI URL discovery, fake skip-trace scrapers, and replacement with real per-county Playwright scrapers.

**Current State:** The infrastructure layer (browser pools, circuit breakers, retry queues, proxy pools, Fargate deployment) has been well-implemented and is production-grade. However, **the data extraction layer still contains substantial fantasy code** that has not yet been refactored per the fix guide. The project has two parallel scraping architectures that are poorly integrated:

- **Path A (Authenticated):** Propelio, Propwire — Uses Playwright with session persistence, stealth, and proxy pinning. Partially functional but lacks CAPTCHA solving.
- **Path B (Generic):** 200+ county/government sources — Still uses Crawl4AI directly with no stealth, no session persistence, no form interaction, and **100% LLM-based extraction from stripped HTML text**. Still completely non-functional for interactive government portals.

**The result:** Jobs return "completed" with empty arrays, the frontend receives inconsistent JSON, and zero real distressed leads or cash buyers are actually extracted from county/government sources. Propelio/Propwire authenticated flows work when not blocked.

## 1. Fantasy / Hallucinated Code — Status of Removal

### 1.1 LLM-Based Data Extraction (workers/llm.py)
**File:** workers/llm.py
**Functions:** `parse_distressed_page()`, `extract_investor_profile()`, `score_buyer_match()`, `suggest_distressed_sources()`
**Severity:** CRITICAL
**Status:** ✅ **COMPLETE** — All four functions removed

**What it does:**
- `parse_distressed_page()`: Takes raw text stripped from HTML via `BeautifulSoup(html, "lxml").get_text()`, sends up to 9,000 characters to OpenAI with a prompt asking for structured JSON, returns listings.
- `extract_investor_profile()`: Scrapes text → sends to LLM → returns investor profile JSON.
- `score_buyer_match()`: Sends buyer + lead to LLM for "match scoring".
- `suggest_distressed_sources()`: Asks LLM to discover source URLs for counties.

**Why it is fantasy:**
- Government/county sites do NOT put structured foreclosure data on their homepages as plain text.
- The LLM hallucinates listings when it cannot find real data.
- No validation that returned addresses exist in the original text.
- No schema enforcement — LLM returns arbitrary JSON shapes.
- Cost: Every scrape costs API credits. With 200+ sources, this is unsustainable.

**Required Action:** Remove all four functions. Keep `_chat()` helper ONLY for non-extraction tasks (e.g., classifying a buyer as "flipper" vs "landlord" AFTER data is already extracted). Replace with per-site DOM parsers in `workers/scrapers/counties/`.

**What it does:**

**Why the original was fantasy:**
- FastPeopleSearch, CyberBackgroundChecks, etc. aggressively block scrapers and sue for TOS violations.
- Google search scraping is instantly blocked after a few requests.

**Required Action:** Remove ALL people-search scrapers. Replace with licensed skip-trace API integration (BatchSkipTracing, TLO, LexisNexis) or document that skip-tracing requires paid API keys. See Fix Guide Phase 1.3.

**Vectors now covered by `playwright-stealth` (50+):**

## 4. What Requires Licensed APIs (Cannot Be Scraped)

| Data Type | Why It Cannot Be Scraped | Recommended API |
|-----------|------------------------|-----------------|
| Skip tracing (owner phone/email) | People-search sites block scrapers; legal liability | BatchSkipTracing, TLOxp, LexisNexis |
| Cash buyer identification | Requires MLS sold data or title records | PropStream, ListSource, REIPro |
| Full property ownership history | County deeds are fragmented, no national aggregator | DataTree, ATTOM, CoreLogic |
| Pre-foreclosure status | Requires lender notification data | RealtyTrac, Foreclosure.com API |
| Tax lien amounts | Often behind paywalls or require parcel search | Regrid, DataTree |

**Budget estimate for APIs:** $500-2,000/month for serious volume.
